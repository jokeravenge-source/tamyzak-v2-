# Stationery sticker assets

The 35 named reference illustrations were individually cut out from the photo
supplied for this notebook, with exterior backgrounds removed and the original
white sticker borders preserved. Each cutout is retained as a transparent PNG;
its SVG counterpart was independently traced from that cutout. The application
uses the SVG versions for resolution-independent resizing and export.

`reference-manifest.json` records the cutout dimensions. The typed runtime catalog
is `src/components/notebook/stickers.ts`. Ten additional SVG illustrations supply
matching flowers, washi tape, a clip, notes, an atom, and motivational cards.
Each asset is its own movable item; the original sheet is never used as a page
object. Do not combine these assets into a single sheet in the application.
